# Environment, settings, caveats
- Harness: `src/bin/bench_external.rs` (new; no existing source edited). rustc 1.99.1, release profile (opt 3, thin LTO, portable target, no target-cpu=native). Windows 11, 8 logical CPUs.
- PKON2: `measure_x(img,&x4_cfg())` pipeline replicated to keep the stream; `x4_cfg()` = inputs [Ab,B,C,D], sign_ctx, Bias::Off, Ens::Off, SubG colour. Replica bytes == `measure_x` bytes (asserted) == prior x4-promotion-verify bytes on all 23 images (re-verified from per_image.csv; the "prior report" column in report.md is blank because of a column-index bug in the cross-check printer, not a data problem). Single-threaded. Timing includes plane split/colour/interleave. No standalone file format: 11-byte header is counted but w/h/layout are passed to the decoder out-of-band.
- JXL / WebP: ffmpeg 9.0.2-full_build-www.gyan.dev (libjxl, libwebp statically linked; the libjxl/libwebp version numbers are not exposed by this build and could not be determined). cjxl/djxl/cwebp/dwebp not installed.
  - JXL: `-c:v libjxl -distance 0 -effort {7|9} -pix_fmt rgb24|rgba -threads 1` (effort 7 = practical, 9 = slow max tested; effort 10 not run). Output is a bare codestream (no container, 0 overhead). Decode: `-threads 1 -i x.jxl -pix_fmt rgb24|rgba`. `-mt` rows: same, default threads, timing only (sizes identical).
  - WebP: `-c:v libwebp -lossless 1 -compression_level 6 -quality 100 -pix_fmt bgra -threads 1` (method 6, max effort). Input rgb24 -> bgra (a=255) / rgba -> bgra swizzle; exactness proven by decode compare. Container: RIFF/VP8L framing ~20 bytes (reported as total vs payload).
  - Timings include process spawn + temp-file I/O; calibration floor (~40-56 ms per call) subtracted in `net` columns.
- PNG: Rust `image` 0.25 / `png` crate, CompressionType::Best, FilterType::Adaptive, no metadata, in-process. Not zopfli/oxipng-class; a stronger PNG optimiser would be smaller (still far larger than the others).
- Inputs: 1024x1024 centre crops (exact pixels) of the decoded images, as in all PKON2 reports; NOT the full-resolution images. 20 JPEG -> rgb8, 3 PNG -> rgba8 (alpha constant 255); layout preserved for all codecs, so PNG-origin raw = 32 bpp and their bpp includes the alpha channel.
- Exactness: every codec, every image, decoded from bytes only and compared byte-for-byte; smoke test also checked truncated streams are rejected and the rgb/rgba<->bgra conversion is exact.
- Timing: best of 2 rounds per image/codec; no warm-up beyond the calibration round trips.
