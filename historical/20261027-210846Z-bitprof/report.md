# PKON2 bit-cost profile

Corpus: the 20 JPEG-origin M6 images (1024-px centre crops, same order/representation as `exp_n3_full`). Arms: `control` = codec 1 = X4 (the frozen M6 reference), `P` = codec 2 = X4 + the P mixer input = the current production default.

Gates: **PASS**. For every image and arm: the profiling-disabled stream and the profiling-enabled stream are byte-identical to the production payload (`pkonfile::encode_with_codec`), the production decoder reproduces the pixels exactly, the profiled encode is deterministic and ends in the same model-state/trace hash, the observed cost equals the sum of costs over every `code` call, decision counts reconcile (mixed + tail decisions == coder calls), every per-(plane, category) cost and count equals the existing `CeEnc` cross-entropy, and the X4 arm equals the production-X4 byte counts recorded by `x4-promotion-verify` (the *frozen M6* X4 used context `In::A`; production X4 is the N3-promoted `In::Ab`, which saves 0.570% on these 20 images: 15,687,437 -> 15,598,046 payload+11 B).

Plane samples per plane (denominator for bits/sample): 20971520 (= 20 images x 1024 x 1024). Total samples (3 planes): 62914560.

**Estimator definitions** (see `src/profile.rs`): *model* = sum of ideal costs `-log2 P` of the probabilities the coder was given (ideal bytes, not the physical range-coder bits); *solo* = ideal cost of one mixer input's own stored probability on the same decisions; *H* = static two-pass empirical entropy of the (plane, node, family) partition per image (optimistic: fits the image, ignores parameter cost); *KT* = sequential Krichevsky-Trofimov code length of the same partition per image (a plain adaptive count per context, includes its learning cost). Gap = model - reference on the same decisions. Only gaps against KT are treated as evidence of avoidable cost; H is shown as the optimistic bound.
